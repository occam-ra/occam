What is pyoccam?`pyoccam` is a standalone, cross-platform Python package that wraps the core OCCAM Reconstructability Analysis tools using modern C++ and `pybind11`. It provides powerful information-theoretic modeling capabilities for categorical data, especially useful for:- Environmental modeling (e.g., landslides, wildfires)- System science- Social and ecological systems- Complex multivariate interactionsOCCAM uses variable-based and state-based search to discover significant structures in complex systems, emphasizing **interpretability** and **information preservation** over black-box prediction.---## ??
